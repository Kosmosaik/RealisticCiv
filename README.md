# RealisticCiv

RealisticCiv is a Fabric mod project aiming to replace Minecraft's compressed vanilla progression with a deeply simulated civilization progression from **primitive survival → agriculture and metallurgy → mechanical/industrial technology → electricity and modern industry → advanced/sci-fi technology**.

The design emphasizes:

- extremely detailed, recursive crafting and manufacturing chains,
- real tools, workstations, machines, skills, knowledge, and prerequisite industries,
- timed server-authoritative work instead of instant crafting for meaningful operations,
- settlers that perform the same underlying production operations as players,
- multiplayer-safe shared settlements and knowledge,
- an expert-modpack-style Quest Book that guides progression without becoming the progression authority,
- increasingly visual in-world crafting, workpieces, machines, and animations.

## Development

Run the client:

```powershell
.\gradlew.bat runClient
```

Run the dedicated development server:

```powershell
.\gradlew.bat runServer
```

Build:

```powershell
.\gradlew.bat build
```

## Package a Clean Source ZIP

Do **not** ZIP the entire local project manually. Use:

```powershell
python .\tools\package_source.py
```

The script writes a clean handoff archive under `dist/` while excluding Gradle caches, build output, local Minecraft runtime files/worlds, IDE state, logs, previous archives, and common secrets.
