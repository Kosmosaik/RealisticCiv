# RealisticCiv

RealisticCiv is a Fabric mod project aiming to replace Minecraft's compressed vanilla progression with a deeply simulated civilization progression from **primitive survival → agriculture and metallurgy → mechanical/industrial technology → electricity and modern industry → advanced/sci-fi technology**.

The design emphasizes:

- extremely detailed, recursive crafting and manufacturing chains,
- real tools, workstations, machines, skills, knowledge, and prerequisite industries,
- timed server-authoritative work instead of instant crafting for meaningful operations,
- settlers that perform the same underlying production operations as players,
- multiplayer-safe shared settlements and knowledge,
- an expert-modpack-style Quest Book that guides progression without becoming the progression authority,
- increasingly visual in-world crafting, workpieces, machines, and animations.

## Current Status

**v0.1.5 — first inventory Hand Crafting/Craft-button milestone.**

The Fabric baseline, material identity, Ground Resources/bootstrap locks, primitive knapping, and timed server-authoritative `WorkActionManager` are established. v0.1.5 now augments the inventory 2x2 grid with an explicit **Craft** button and routes recognized Hand Crafting through that existing server runtime. The first operation is Branch + persistent Flint Flake → ~5 seconds of `Shape Wooden Handle` → Wooden Handle. The client sends only a request; the server re-resolves the grid, reserves input, validates the tool capability, owns timing/cancellation, and grants the result.

The next planned gameplay milestone after local v0.1.5 verification is **v0.1.6 — Fibre/Cordage Bootstrap**. Fibre will remain source-identified rather than becoming a generic naturally harvested `Plant Fibre`: Tall Grass → Long Grass Stems → Prepared Grass → Primitive Grass Cordage is the emergency route, with Nettle planned as the first better wild fibre source. See `docs/14_CURRENT_STATE_AND_HANDOFF.md`, `docs/22_FIBRES_CORDAGE_AND_TEXTILES.md`, and `docs/23_HAND_CRAFTING_UI.md`.

## Development

Run data generation:

```powershell
.\gradlew.bat runDatagen
```

Run the client:

```powershell
.\gradlew.bat runClient
```

Run the dedicated development server:

```powershell
.\gradlew.bat runServer
```

Build:

```powershell
.\gradlew.bat build
```

## Package a Clean Source ZIP

Do **not** ZIP the entire local project manually. Use:

```powershell
python .\tools\package_source.py
```

The script writes a clean handoff archive under `dist/` while excluding Gradle caches, build output, local Minecraft runtime files/worlds, IDE state, logs, previous archives, and common secrets.
