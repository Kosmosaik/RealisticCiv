# Quest Book Visual References

These images are **design mockups**, not final distributable game assets.

They exist to communicate the intended UI direction to future developers/assistants:

- expert-modpack-style node graphs,
- clearly distinguishable major and minor quests,
- obvious dependency lines,
- chapter navigation at the side,
- completed / available / locked states,
- selected-quest details and prerequisite navigation.

The implementation should preserve the structural ideas rather than attempting to reproduce the mockups pixel-for-pixel.
